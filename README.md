# Tactile Knit Poster

> 使用许可：仅限个人非商业使用。商业项目、客户交付、广告、付费服务和转售需要另行授权。

一个用于 Codex 的海报生成 skill：把用户文案或一张贴图，转成 4:5 竖版的针织纱线 / 刺绣布贴海报。

它不是简单地给图片叠加毛线纹理，而是把针织材质、中央主体、字母边框和编辑信息区重新组织成一张完整海报。

## 能做什么

- 根据文案生成一张针织纱线风格海报。
- 根据上传的贴图或完整海报进行风格转换。
- 贴图模式默认：保留主体，重做针织背景、边框和版式。
- 贴图模式默认保留原海报已有的栏目、品牌标识、签名、文字块和底部信息；只有明确要求时才删除或替换。
- 默认一次生成单张 4:5 竖版栅格图。
- 根据主题生成相关的字母围绕边框，而不是使用无关品牌词。
- 标题保持克制，让中央布贴、纱线和版式共同承担视觉重点。
- 左上角栏目、右上角品牌标识、底部信息栏均为可选，不会强制添加。

## 安装

将整个仓库文件夹复制到 Codex 的 skills 目录：

```bash
mkdir -p ~/.codex/skills/tactile-knit-poster
cp -R . ~/.codex/skills/tactile-knit-poster/
```

如果你是从 GitHub 克隆：

```bash
git clone https://github.com/zhangxinfang2018-sudo/tactile-knit-poster.git ~/.codex/skills/tactile-knit-poster
```

安装后重新打开 Codex，或新建一个对话，让 skill 被重新加载。

## 用法一：根据文案生成

在对话中直接输入：

```text
$tactile-knit-poster

生成一张 4:5 竖版海报。

主标题：春日散步
副标题：把时间还给风
```

也可以补充配色、主题或情绪：

```text
$tactile-knit-poster

生成一张 4:5 竖版海报。
主标题：春日散步
副标题：把时间还给风
配色：浅蓝、奶油白、珊瑚粉
感觉：柔软、轻松、手工感
```

如果只给标题和副标题，skill 会自行推断合适的针织材质、颜色角色和构图。

没有参考图时，skill 会根据内容判断版式：短口号可能使用主题字母边框；人物、动物或物件会作为中央主体；教程、清单和数字内容通常使用堆叠标题布贴；季节和生活方式主题可以加入少量相关针织小元素。字母边框和小元素都不是每张海报的固定装饰。

用户指定的颜色、版式、边框或元素始终优先。没有指定配色时，会自动建立背景、主体、强调色和中性色组成的 2–4 色角色关系。

## 用法二：转换一张贴图

把需要转换的图片附在对话中，然后输入：

```text
$tactile-knit-poster

保留这张海报的核心主体，
重新设计成针织纱线风格，
保留主体但重做背景、边框和版式。
```

默认会保留主体的身份、轮廓、姿态和关键识别细节。参考图的处理方式取决于图片类型：

### 有背景的完整海报：严格版式转化

如果参考图有完整背景色和已经完成的版式，默认锁定：

- 画布比例和裁切；
- 背景色和颜色角色；
- 主体位置和比例；
- 标题层级和信息区；
- 边框方向和构图骨架。

默认只做针织纱线、刺绣和布贴材质转换，不自由添加无关元素，也不擅自删除信息。若想重新排版，需要明确写“允许重新设计背景、边框和版式”。

### 透明 PNG：自由排版转化

如果上传的是透明 PNG 或孤立主体，skill 会保留主体轮廓、姿态和主要颜色，并重新设计针织背景、边框和信息区。可以加入少量与主题相关的小元素，但不会堆叠无关装饰。

无论哪种情况，都会重新处理为针织材质：

- 全幅针织背景；
- 中央布贴或徽章结构；
- 与主题有关的纱线字母边框；
- 标题、辅助文字和信息区的位置；
- 颜色关系与纱线材质。

如果原图中的文字必须准确保留，建议在请求中重新打出来：

```text
$tactile-knit-poster

保留图片中央的三个杯子和整体主体，重做成针织纱线海报。
需要保留的文字：过滤忧愁、穿戴生活。
```

完整海报默认会保留原图中已经存在的顶部栏目、品牌标识和底部信息，只将它们转换为针织材质并融入原有构图。若不需要这些元素，请明确写“去掉原图中的品牌和底部信息”。

## 系列材质统一

如果你比较多张结果并指出“哪些图的针织质感比较好、哪张偏离”，skill 会把你认可的图片作为材质标准，不会把所有图片平均混合。

默认统一以下内容：

- 中等粗细的背景针织；
- 清晰但不过大的 V 形针脚；
- 相近的纱线股数、绒感和起伏；
- 相近的柔和光照和阴影；
- 前景文字或边框只比背景厚约 1.2–1.5 倍。

背景不会默认变成过细、过密、过于整齐的细针织布。只有明确要求“背景毛线更细”时，才降低一个材质等级。

## 你可以控制的内容

可以直接提供：

- 主标题、副标题；
- 配色或颜色角色；
- 想保留的主体；
- 想省略或保留的栏目、品牌、底部信息；
- 标题大小、留白、边框字母的主题方向；
- 参考图的视觉倾向。

例如：

```text
标题小一点，四周留白增加，背景毛线更细，
边框字母围绕主体，并根据“春日散步”生成相关英文短语。
```

不需要说明“第几张图负责构图、哪张图负责配色”。如果上传了多张风格图，skill 会根据构图、主体比例、色彩关系和边框形式自动判断各自的作用。

## 输出规则

- 一次只生成一张海报。
- 默认比例为 4:5 竖版。
- 输出是栅格图片，不是 HTML、SVG 或可编辑矢量文件。
- 针织背景使用较细、更密的纱线；标题和边框可以使用更粗的立体纱线，以维持层级。
- 主标题默认不会铺满画面，也不会压过中央主体。
- 文案生成模式下，用户没有提供品牌、日期或底部信息时，不会强行复制参考图中的品牌和栏目。
- 有背景的完整海报默认锁定版式和色系，只转换材质；透明 PNG 默认允许自由设计背景、边框和版式。

## 注意事项

### 1. 文字准确性需要检查

图像生成模型对中文、英文小字、数字和品牌标识的准确率仍然有限。尤其要检查：

- 中文标题是否写对；
- 字符是否缺笔、粘连或变形；
- 英文边框是否出现随机字母；
- 小字号栏目和底部信息是否可读；
- 需要保留的 Logo 是否被改写。

重要文字尽量在提示词中逐字提供，并在生成后人工核对。对非常严格的商业文案，建议把图片作为视觉底稿，再在设计软件中重新排字。

### 2. “参考图”不是“复制图”

参考图用于学习构图、材质、比例、色彩角色和版式逻辑，不应直接复制其中的 Logo、品牌名、日期、文案或独特图形。使用他人图片、字体、商标和品牌资产前，请确认你拥有相应授权。

### 3. 贴图模式要说清楚保留什么

如果只说“转成针织风格”，模型可能只保留大致颜色或主题。最好明确主体，例如“保留三个杯子的数量、叠放关系和中心位置”。如果原图文字重要，也要单独提供文字内容。

### 4. 主体与文字的比例是设计决策

这套风格强调“中央纺织主体 + 克制标题”，不是大字报。若需要更醒目的标题，可以明确说“标题稍微放大”；若希望更接近布贴海报，可以说“标题缩小、增加主体周围的纺织留白”。

### 5. 小信息区可以省略

在文案生成模式中，左上角栏目、右上角标识和底部三段式信息栏都不是必需元素。没有真实内容时，建议省略，或明确允许生成与主题相关的短辅助文案；不要默认填入品牌名、日期或伪造 Logo。贴图模式则默认保留原图已有的信息区，除非你明确要求删除或替换。
